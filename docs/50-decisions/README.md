# Architecture Decision Records

## Process

1. `ADR-0000-template.md` dosyasını sıradaki numarayla kopyala.
2. `Proposed` olarak seçenekleri ve etkileri yaz.
3. Onay gereksinimini `AGENTS.md` kurallarına göre belirle.
4. Açık onayla `Accepted` veya `Rejected` yap.
5. Uygulamayı, ilgili belgeleri ve changelog'u güncelle.
6. Eski kararı silme; yeni ADR ile `Superseded` yap.
